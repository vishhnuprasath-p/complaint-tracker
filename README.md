# 🚀 Public Complaint Tracking System

A full-stack web application that allows users to submit, track, and manage public complaints efficiently.

---

## 🌐 Live Demo

👉 https://complaint-tracker-14fk.onrender.com

---

## 📌 Features

* 📝 Submit complaints with name, category, and description
* 📊 View all complaints in a structured table
* 🔄 Update complaint status (Pending / In Progress / Resolved)
* ❌ Delete complaints
* 💾 Data stored using SQLite database
* ⚡ Real-time updates without page refresh

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** SQLite
* **Deployment:** Render

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/vishhnuprasath-p/complaint-tracker.git
cd complaint-tracker
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the server

```bash
node app.js
```

### 4️⃣ Open in browser

```
http://localhost:3000
```

---

## 🧠 How It Works

* Users submit complaints through the form
* Data is sent to backend APIs (Express)
* Complaints are stored in SQLite database
* Frontend fetches and displays data dynamically

---

## ⚠️ Note

* The app is deployed on a free Render service
* It may take a few seconds to load after inactivity
